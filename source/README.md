# Figure source files

Figure 1 is drawn with native TikZ in the manuscript source. This folder contains the editable SVG masters and PDF exports for the three external figure assets used as Figures 2-4 in the current manuscript.

Figure 3 is supported by figure_source_data/figure3_case_status.csv. Figure 4 is supported by figure_source_data/figure4_instrumentation_cost.csv; the row for the separate append-only harness is retained in the CSV but is not plotted as one of the three logging modes.

Figure 2 is an explanatory rendering of the recovered EPLO control-flow sequence. It is not a complete event ledger; the manuscript states that the archived trace lacks stable identifiers for every event.

These figure files match the manuscript labels and captions. The package intentionally contains no generator for the withdrawn EPLO ranking display.
